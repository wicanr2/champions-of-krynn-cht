# 翻譯工作檔

正式譯文表在 `text/`；這裡保存產生它們的批次、提示詞與輔助程式（使用者 2026-10-21 決定進版控）。

| 目錄 | 內容 |
|---|---|
| `zh-TW/` | 繁中譯文批次（`batches`、`ecl-batches`、`ui-batches` 為輸入，`done`、`ecl-done`、`ui-done` 為譯文）與 `PROMPT.md` |
| `ja-ko/` | 日文、韓文批次（`batches` 輸入，`done-ja`、`done-ko` 譯文）、術語表草稿、輔助表 `aux-ja`、`aux-ko` 與各提示詞；合併工具 `tools/jako_merge.py` |
| `journal/` | 手札與攻略的轉錄、翻譯批次與提示詞（`en`、`zh`）、英文手札逐字稿 `journal.en.tsv` 的來源 |

批次輸入含遊戲英文原文，英文手札逐字稿是手冊原文；著作權屬原權利人，只在本 private repo 保存。
