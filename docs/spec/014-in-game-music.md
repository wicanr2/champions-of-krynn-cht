# 014 遊戲中配樂

狀態：**READY**（作曲與素材契約，§2–§3）；播放接入 §4 為 **DRAFT**，觸發字串待實機盤點。Issue：#16。日期：2026-10-19。

使用者指示（2026-10-19）：以原版 MIDI 音樂為基礎，用 Codex 產生本作專屬配樂，至少 10 首；觸發時機由 Claude 決定；預設開、可在切換列關閉。

## 1. 原版證據

| 項目 | 內容 | 等級 |
|---|---|---|
| 原版何時播音樂 | 冷啟動到 demo 只在第 1,869M 步讀一次 `MIDI.DAX`；從開場劇情到屯墾區不讀（`probe -reads-of midi`，`workplace/probe/music`） | 已證實（兩段路徑） |
| `MIDI.DAX` 內容 | 5 個區塊，解開後都以 x86 跳躍表（`E9 xx xx`）開頭，是「播放程式＋樂譜」的模組，不是標準 MIDI 檔 | 已證實 |
| 5 個區塊的關係 | 原版請求區塊 3；在 scratch 層放對調檔頭的副本讓標題載入其他區塊：區塊 3 寫 OPL（1,749 筆、15.4 秒），區塊 2 輪詢 331h（MPU-401 狀態），1、4、5 不寫 OPL | 已證實行為；「5 個區塊是同一首標題曲的不同音效卡版本」是推測 |
| 素材 | AdLib 版標題曲的 OPL 序列 `workplace/probe/music/t3/opl.log`，原聲 `orig.wav`、Nuked 渲染 `render.wav` | 已證實 |

結論：原版只有一首約 15 秒的標題曲，遊戲中沒有背景音樂。新配樂全部是以標題曲動機與 OPL 音色為基礎的新編曲。

## 3. 素材契約（Codex 產出，`workplace/music/out/`）

- 每首：`<key>.mid`（編曲原稿）、`<key>.opl`（OPL2 寫入序列，每行 `秒 暫存器 值`，十六進位暫存器與值）、`<key>.wav`（`cmd/cok-opl-render` 48 kHz 立體聲渲染）。
- 音色只用 OPL2（9 旋律聲道、波形 0–3，不用節奏模式與 OPL3 暫存器），優先沿用標題曲 `opl.log` 中的音色暫存器組；音色與 cok-play 內建合成器一致。
- 循環曲標 `loop_start`、`loop_end`（秒），接縫無爆音；非循環曲標總長。長度：循環曲 60–150 秒，短曲 3–12 秒。
- 每首以標題曲的旋律或和聲動機發展，`manifest.json` 寫出引用的動機（小節、音高序列）、調性、速度、長度、SHA-256、生成方式。
- 權利註記：衍生自 SSI 原版標題曲的新編曲，隨可散布包私下分享（CONTEXT 決策表 2026-10-19）。
- 響度：各曲 RMS 相近（±3 dB），峰值不削波。

## 4. 播放接入（DRAFT）

- cok-play 混音器加一條音樂軌（PCM），與原版 OPL、喇叭聲道並存；原版音效照常。
- 觸發來源（adapter 已有的訊號）：GEO 地圖鍵（`text/map-geo.tsv`）、路徑 C 底列選單、路徑 B 訊息。字串以實機盤點為準，寫成對照表 `text/music-cues.tsv`。
- 換曲淡出淡入 1 秒；同曲不重播；短曲播完回到前一首。
- 切換列加音樂開關，預設開；關閉時不混入音樂軌，輸出與原版相同。
- 收據：開關關閉時與原版 WAV 一致；開啟時三個場景（屯墾區、大地圖、戰鬥）各觸發正確曲目；2 倍、3 倍畫面不變。
