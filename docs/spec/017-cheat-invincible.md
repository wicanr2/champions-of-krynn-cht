# 017 作弊：我方無敵

狀態：**CONFORMED**（2026-10-20）。

使用者指示（2026-10-20）：增加作弊選項，戰鬥與冒險過程中我方 HP 不減少，不進入昏迷、中毒等異常狀態。

## 1. 記憶體欄位（docs/re/010）

| 欄位 | 位置 | 等級 |
|---|---|---|
| 隊伍串列頭 | `DS:609A`（線性 `12DFA`）遠指標，指向第一位隊員紀錄 | 已證實（demo 三人隊、斯拉托二人隊、開場一人隊三份傾印唯一共同位置） |
| 下一位 | 紀錄 `+0x17F` 遠指標；戰鬥中會接到怪物紀錄，結尾為 0 | 已證實 |
| 目前 HP | 紀錄 `+0x197` | 已證實（demo 戰鬥 SIR RINGWALD 61→44；docs/re/009） |
| 健康狀態 | 紀錄 `+0x188`，0 為正常 | 已證實（四隻 BOZAK 被殺時 0→6 或 0→10，同時 HP 歸 0） |
| 陣營 | 紀錄 `+0x18A`，我方 0、怪物 1 | 已證實（三份傾印 6 名隊員皆 0，13 隻怪物皆 1） |
| 效果串列 | 紀錄 `+0xE3` 遠指標，9 bytes 一筆，`+0` 類型、`+5` 下一筆 | 已證實（麻痺 `0x34` 加在伊斯坦串列尾端） |

## 2. 行為

- 開關：切換列「無敵」與 F1，預設關，不記住（每次啟動都是關）。
- 開啟時，遊戲寫入我方紀錄（串列中 `+0x18A` 為 0 者）的下列欄位會被立即還原：
  - `+0x197` 變小（扣血、中毒持續傷害）。
  - `+0x188` 由 0 變成非 0（昏迷、瀕死、死亡、石化，以及中毒致死）。
  - `+0x18A` 由 0 變成非 0（被魅惑而倒戈）。
- 每格開頭走訪我方效果串列，把有害類型解除連結（前一個連結改指向下一筆）：`0x34` 麻痺（本作證實），`0x1F` 失能、`0x21` 失明、`0x2A` 緩慢、`0x33` 蛇咒、`0x35` 睡眠（同引擎《詛咒藍符》反組譯，本作為假說）。移除的 9 bytes 不釋放。遊戲當下仍會印出「被麻痺了」等訊息，下一格就移除。
- 回復 HP、狀態由非 0 回到 0（治療、復活）照常。
- 不處理：上列以外的效果類型（代碼未證實，不猜）、屬性與等級吸取。開關關閉時完全不介入，畫面與記憶體與原版相同。
- 已知影響：開啟時讀檔或換隊員，若新資料的 HP 較低或狀態異常，也會被擋下而沿用原值。要讀入原本的數值，先關閉再讀檔。

## 3. 實作

- dosgolem session：選用擴充介面 `WriteGuard`（觀察者實作才啟用）。每次 `Advance` 開頭呼叫 `GuardRange`（可經 `GuardMemory` 讀寫記憶體）取得要監看的線性位址範圍，以 `machine.WatchWrites` 監看；寫入改變值時呼叫 `GuardWrite`，回 true 就把該 byte 寫回舊值。
- `apps/cok/cheat.go`：`Invincible` 走訪隊伍串列，範圍取所有我方紀錄的最小與最大位址；判斷寫入是否落在某筆紀錄的 `+0x197`、`+0x188`。
- cok-play：切換列項目、F1、腳本動作 `cheat`。

## 4. 收據

- 單元測試：串列走訪（遇怪物停在我方、遇迴圈停止）、HP 變小還原、狀態 0→非 0 還原、治療照常、關閉時不介入。
- 實機 `tools/g10-cheat-receipt.sh`：cok-play 冷開機不送鍵跑 demo 戰鬥（`-clock 100`，8,840 畫格，1.70e9 步），無敵關、開各一次。開啟時還原 6 次扣血，結束時 SIR RINGWALD 75、VARIANNA 48、LYN SWIFTFOOT 40，狀態皆 0；關閉時不監看。兩次記憶體雜湊不同（開啟確實改變了執行）。
- 同腳本第二段：預建六人隊大地圖戰鬥（重播 explore3，`cmd/cok-promo -cheat` 以 machine 寫入監看實作同一判斷）。5.0e9 步時原版三人 HP 0、狀態 4（昏迷）；開啟時還原 7 次、移除有害效果 4 筆，六人全員狀態 0、HP 20–26，串列沒有有害類型，原有效果（`0x12`、`0x5C` 等）保留。
- 切換列多一項後，沒有 HD 素材時的寬度超過 320 像素，繁中、简中的「無HD素材」縮成「無HD」；`tools/g7-toolbar-receipt.sh` 通過。
