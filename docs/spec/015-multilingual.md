## 2. 語系架構（#17）

- 語言代碼：`zh-TW`、`zh-CN`、`ja`、`ko`、`en`，另有 `orig`（原版畫面，不覆繪）。
- 譯文表沿用 `text/<表>.<代碼>.tsv`，key 與事件表共用，不為各語言另開事件表。缺表或缺 key 時顯示原版英文，並由檢查腳本報漏譯。
- 字型依語言選：`zh-TW` 用倚天或 Unifont 子集；`zh-CN`、`ja`、`ko` 用 Unifont 子集，字集由該語言的正式譯文重建；`en` 用 §3 的英文字型。
- `cok-play` 新增 `-lang`；啟動器第一次執行時列出語言，選擇寫進使用者設定檔，之後沿用。切換列與快捷鍵在已載入的語言與原版之間循環，切換不重開遊戲、不動記憶體（同規格 011）。
- 發行包帶全部語言的譯文與字型。`tools/term-check.sh`、行寬與字型覆蓋檢查改成逐語言執行。
- 驗收：每種語言跑 G5 七場景同狀態 A/B（範圍外差異 0），另跑一次 `zh-TW` 回歸，確認雜湊與改動前相同。

## 3. 英文版（#18）

### 3.1 字型

- 原版文字格 8×8，欄 c、列 r 的左上角在 (8c, 8r)；字串本身大小寫混排，但字型只有大寫字模，所以畫面全是大寫（幽靈騎士規格 001 §1，已證實；本作沿用時等級為強推論，#18 重驗）。新字型照字串原樣顯示大小寫。
- 新字型維持一字一格的等寬排版，原版的欄位對齊與游標位置才不會跑掉。
- 3 倍畫面每格 24×24，可以畫出有襯線、筆畫平滑的字；2 倍為 16×16。候選字型限 SIL OFL 或同等可散布授權，點陣化後做對照圖給使用者選，選定才進產品路徑。
- 數字、標點與框線字元要逐字核對；原版的特殊字元（例如方向箭頭）保留原字模。

### 3.2 覆繪方式

- 英文原文就是比對鍵，所以 `en` 不需要譯文表：攔截到的原文直接以新字型重繪，清除與座標沿用現有三條路徑（規格 001–004）。
- 組句、名稱、半形規則（規格 004、005、013）在 `en` 下停用，原文照原樣輸出。
- 需要驗的是字寬溢出與跨行：原版字串剛好塞滿 40 欄時，新字型不能超出原版的清除範圍。

### 3.3 手札與酒店傳聞

- 原版提示「請讀手札第 N 則」時，開啟與規格 007 相同的面板，內容是英文 Adventurer's Journal 第 N 則原文。
- 原文從使用者的 PDF 抽取成 `journal.en.tsv`，放 `workplace/`，不進 Git，打包時才放進發行包（CONTEXT「可散布 patch 包維持全放，只私下分享」）。
- 校對比照 docs/re/002：PDF 為主，mocagh 版為輔；每則記錄頁碼與段落。
- 攻略面板與地圖攻略點出自《軟體世界》中文攻略，`en` 下的處理待定（§6）。

## 4. 簡體中文（#19）

- 轉換：`zh-TW` 正式譯文經 OpenCC（`tw2sp`，台灣正體到大陸簡體並轉詞彙），再套 `text/glossary.zh-CN.tsv` 修正專有名詞與遊戲用語。OpenCC 版本與設定在 Docker 映像內鎖定。
- 專有名詞以繁中術語表為準逐字轉簡，不改音譯用字；兩岸慣用詞差異在詞彙表逐條決定，OpenCC 轉換結果全量列表後人工抽查。
- 檢查：轉換後與繁中逐 key 比對控制碼、placeholder 與長度；術語一致性由 `term-check` 驗證。
- 簡中只是轉換，不另外重譯；繁中修正後重跑轉換即可同步。

## 5. 日文與韓文（#20）

- 底稿：英文原文（`workplace/text/*-source.tsv`），參考繁中譯文確認語意，譯文進 `text/<表>.ja.tsv`、`text/<表>.ko.tsv`，`source` 欄標 `machine`。
- 流程依 `~/.claude/knowledge-base/workflows/batch-subagent-localization.md`：先定日韓術語表（人名、地名、種族、職業、法術、物品），試譯一批給使用者看，風格定案後才全量；合併時逐 key 核對不可變欄位與控制碼，再做全域譯名掃描。
- 人名、地名：日文用片假名，韓文用韓文音譯；Dragonlance 有日、韓正式譯名的，查到可引用的出處才採用，否則依音譯規則並在術語表標「音譯」。
- 版面：日文與韓文通常比中文長，ECL 文字視窗與底列選單的行寬要逐條檢查；超出時改譯文，不縮字（AGENTS 第 2 節，規則 81）。
- 字型：Unifont 涵蓋平假名、片假名、常用漢字與韓文音節；字集由正式譯文重建，缺字由檢查腳本報出。
- 發行包與 README 註明日文、韓文為機器翻譯、未經母語者校對。
