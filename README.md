# 《克萊恩英豪》繁體中文化（Champions of Krynn）

用 [dosgolem](https://github.com/wicanr2/dosgolem) 執行 SSI 1990 年 DOS 版《Champions of Krynn》，
在原版輸出的畫面上覆繪繁體中文，並提供 HD 版本。原版 EXE 與資料檔不修改。

## 現況

G0 治理就位，其餘階段見 [Issues](https://github.com/wicanr2/champions-of-krynn-cht/issues)。目前真相見 [CONTEXT.md](CONTEXT.md)，
協作規則見 [AGENTS.md](AGENTS.md)。
