# 翻譯指引

《Champions of Krynn》（中文名《克萊恩英豪》）繁體中文化的翻譯規則。每個翻譯批次開工前先讀本檔與
[`glossary.tsv`](glossary.tsv)。規則沿用幽靈騎士（同系列續作），定案來源見 `AGENTS.md` 第 3 節與 `CONTEXT.md`。
本作是克萊恩三部曲第一部，劇情發生在幽靈騎士之前：隊伍受卡爾爵士之命，從屯墾區出發追查龍人與麥坦尼的陰謀。

## 文風

- 忠實正式，奇幻古典語氣。貼近原文語意，不增刪情節，不加註解。
- 龍槍（Dragonlance）世界觀：騎士、死亡騎士、龍、神祇。用詞可帶古風，例如「汝」「吾」只在原文刻意古雅時使用，
  一般對話用自然的書面語。
- 原文全大寫是字型限制，不代表喊叫；依語意判斷語氣。
- 引號：原文的 `'…'` 對話譯成「…」，引號內再引用用『…』。
- 標點用全形：，。！？：；「」『』（）……。不用全形空白。

## 術語

- 專名一律依 `glossary.tsv`。術語表繼承幽靈騎士（source 欄 `dkk:` 開頭），已含通行譯名修正（例：Paladin 聖騎士、Ranger 遊俠、詛咒）。
- 表內沒有的專名：龍槍小說人物、地名優先用《龍槍編年史》中譯本通行譯名（例：Caramon 卡拉蒙、Tanis 坦尼斯、Raistlin 雷斯林）；
  其餘參考軟體世界攻略（`walkthrough/` 第 16–18 期）的譯名，與現代通行用法明顯不同時改用通行譯法；都沒有就自行音譯或意譯。
  批次輸出的 note 欄寫「新詞：英文=中文」，合併時統一收斂進術語表。
- 同一英文專名在整個遊戲只用一種譯法。
- 攻略面板與地圖點也依術語表，譯名優先序為遊戲譯文、術語表、提示書；雜誌異寫登在 `walkthrough-terms.tsv`。
- 手札（Journal Entry）與酒館傳聞（Tavern Tale）以編號稱呼時寫「手札第 N 則」「傳聞第 N 則」。
- 遊戲機制詞（AC、THAC0、HP、等級）依術語表；表內沒有的保留英文縮寫。

## 硬規則

- `key` 一字不改，列數與順序與輸入批次相同。
- 譯文單行，不含 tab、換行、控制字元；頭尾不留空白（原文的尾端空白不需保留）。
- 只用 Big5 能編碼的字（開發字型為倚天）。異體字改用 Big5 內的通行字。
- 原文是雜訊（不成句的位元組、亂碼、單獨的符號或代碼）時，譯文寫 `-`，該列不進正式檔。
- 原文被拆成多則接續的片段（看 `prev`、`next` 欄）：譯文要能依原順序接起來讀通。片段開頭若接在名字或前一句之後，
  不要另起主詞；必要時把語意放在較完整的那一則，另一則譯短。
- 數字、角色名、物品名若出現在原文中，照原樣保留在對應位置。
- 玩家必須輸入的字（密語、謎語答案）寫成「中文（ENGLISH）」，例「迪妮莎（DENISSA）」；謎題必要時註明答案要輸入英文。遊戲只接受英文輸入，不改判定。
- 敘述對玩家隊伍用「你們」；NPC 對白依語境，對單一對象可用「你」。

## 介面字串

- 介面字串（選單、狀態、職業、法術名）要短：中文字數不超過英文原文字元數，越短越好。
- 不加熱鍵標記，熱鍵由程式另外處理。
- 字串前後的空白補位不譯；`Name`、`AC`、`HP` 這類欄位標題照術語表。
- 程式碼殘渣、不成詞的位元組、檔名、DOS 錯誤訊息以外的系統字串若看不出用途，譯 `-`。

## 輸出格式

每批輸出 `done/batch-NN.tsv`（UTF-8、tab 分隔），表頭：

```
key	translation	note
```

note 只寫需要人工確認的事：新詞、不確定的語意、接句困難。沒有就留空。
